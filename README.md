# Osints-Hunter
Perangkat ( Open Source Intelligence )(OSINT) modern yang ditulis dalam bahasa Python dengan antarmuka baris perintah (CLI) bergaya *cyberpunk* neon. Dirancang bagi peneliti keamanan, pemburu *bug bounty*, dan pelajar untuk melakukan pengintaian terhadap target dengan hanya memanfaatkan sumber-sumber yang tersedia untuk publik.
